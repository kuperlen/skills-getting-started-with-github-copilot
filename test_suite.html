🧪 Task Manager - Quick Test Suite

Test 1: Check DOM Elements

Verify that all required HTML elements are present.

Test 2: Add Task Functionality

Test the ability to add a new task.

Test 3: LocalStorage Persistence

Verify data is saved and persisted correctly.

Test 4: Check Console Output

View console logs to debug issues. Open DevTools with F12 to see Console tab.

How to open browser console:
• Windows/Linux: F12 or Ctrl+Shift+I
• Mac: Cmd+Option+I

Expected messages:
• "Task Manager initialized with X tasks"
• "Tasks saved to localStorage: [...]"
• "Tasks loaded from localStorage: [...]"

Test 5: Manual Testing Checklist

  • Type "Buy groceries" and click "Add Task"
  • Task should appear in the list
  • Character counter should show the text length
  • Click checkbox to mark task complete
  • Task should have strikethrough and faded appearance
  • Statistics should update (Total: 1, Completed: 1, Pending: 0)
  • Click Delete button to remove task
  • Add more tasks and test filters (All, Active, Completed)
  • Refresh the page (F5) - tasks should still be there
  • Mark tasks complete and click "Clear Completed Tasks"

Run the tests above to verify all features are working correctly.
